# راهنمای ورود شرکت‌ها

## بخش ۱: برای شرکت‌ها (این بخش را برای شرکت‌ها بفرستید)

**نشانی ورود:** https://favapark.liara.run/auth (یا دکمهٔ «ورود» در سایت)

| | |
|---|---|
| نام کاربری | **شناسهٔ ملی شرکت** (۱۱ رقم). با رقم فارسی یا انگلیسی، هر دو پذیرفته می‌شود. |
| رمز عبور اولیه | **شمارهٔ موبایل مدیرعامل**، همان شماره‌ای که در فهرست شرکت‌های پارک ثبت شده است؛ مثلاً `09121234567` |

۱. نام کاربری و رمز اولیه را وارد کنید و «ورود» را بزنید.

۲. **در اولین ورود** صفحهٔ «تعیین رمز عبور» باز می‌شود. یک رمز تازه انتخاب کنید و دوباره همان را تکرار کنید. رمز تازه:
   - حداقل ۸ کاراکتر باشد؛
   - رمز رایج یا قابل حدس نباشد (مثل ۱۲۳۴۵۶۷۸ یا تکرار یک حرف)؛
   - شناسهٔ ملی شرکت در آن نباشد؛
   - با رمز اولیه یکی نباشد.

   از این به بعد با **شناسهٔ ملی و رمز تازه** وارد می‌شوید و شمارهٔ موبایل دیگر به‌عنوان رمز کار نمی‌کند.

۳. بعد از ورود، صفحهٔ «داشبورد صاحب شرکت» باز می‌شود. در آن‌جا مشخصات شرکت، لوگو، محصولات، تصاویر، کاتالوگ و ویدئو را ویرایش و «ذخیره» کنید.

۴. اگر شرکت شما **قبلاً در نمایشگاه منتشر شده**، تغییرات فوراً در سایت دیده نمی‌شوند. ابتدا مدیر پارک بررسی و تأیید می‌کند و تا آن زمان وضعیت آن‌ها «در انتظار بررسی» است. اگر شرکت هنوز منتشر نشده، پس از تکمیل اطلاعات «ارسال برای بررسی» را بزنید.

۵. گزینهٔ «مرا به خاطر بسپار» را روی رایانهٔ مشترک یا عمومی خاموش کنید تا با بستن مرورگر از حساب خارج شوید.

۶. اگر چند بار پشت سر هم رمز اشتباه وارد کنید، ورود برای چند دقیقه بسته می‌شود («تلاش‌های ناموفق زیاد بوده است»). کمی صبر کنید و دوباره تلاش کنید.

۷. **فراموشی رمز:** با مدیر پارک تماس بگیرید. بازیابی خودکار وجود ندارد. مدیر رمز را به شمارهٔ موبایل مدیرعامل برمی‌گرداند و شما دوباره از مرحلهٔ ۲ شروع می‌کنید.

## بخش ۲: برای مدیر پارک

### ساختن حساب شرکت‌ها

این کار یک بار انجام می‌شود، و هر بار که فهرست شرکت‌ها تغییر کرد دوباره.

روی رایانه‌ای که Python، Bun و دسترسی به دیتابیس سایت دارد اجرا کنید. نشانی دیتابیس را از پنل لیارا بردارید؛ اگر از بیرون لیارا وصل می‌شوید، دسترسی عمومی دیتابیس را موقتاً روشن کنید و بعد از کار خاموش کنید.

```bash
pip install openpyxl
python3 scripts/generate-national-id-logins.py "فایل-شرکت‌ها.xlsx"
```

خروجی آن فایل `scripts/company-national-id-logins.json` است. این فایل را جایی نگذارید و برای کسی نفرستید؛ هش شماره‌های موبایل در آن است.

```bash
DATABASE_URL="postgres://…?sslmode=require" bun run scripts/provision-national-id-logins.ts
```

این اجرا چیزی تغییر نمی‌دهد و فقط گزارش می‌دهد کدام ردیف به کدام شرکت وصل می‌شود و کدام‌ها پیدا نشدند. اگر گزارش درست بود:

```bash
DATABASE_URL="postgres://…?sslmode=require" bun run scripts/provision-national-id-logins.ts --apply
```

- اجرای دوباره بی‌خطر است: حساب‌هایی که رمز خودشان را گذاشته‌اند دست نمی‌خورند.
- حساب‌ها در «مدیریت کاربران» (`/admin/users`) با ستون «شناسه ملی» دیده می‌شوند.

### شرکتی که شناسهٔ ملی‌اش در فهرست نیست

۱. شرکت با **ایمیل** در صفحهٔ ورود، «ثبت‌نام» می‌کند.

۲. مدیر در «مدیریت کاربران» آن حساب را پیدا می‌کند و از ستون «شرکت»، شرکتش را انتخاب می‌کند.

### برگرداندن رمز فراموش‌شده

در پنل لیارا، بخش دیتابیس، این دستور را اجرا کنید (به‌جای `X` شناسهٔ ملی شرکت):

```sql
UPDATE users SET must_change_password = true WHERE national_id = 'X';
DELETE FROM sessions WHERE user_id = (SELECT id FROM users WHERE national_id = 'X');
```

سپس دستور `--apply` بالا را دوباره اجرا کنید. رمز آن شرکت دوباره شمارهٔ موبایل مدیرعامل می‌شود و در ورود بعدی باید رمز تازه بگذارد.
